# FROSTBOIL — the kettle that boils ice

One 1024×1024 catalogue photograph of an impossible gadget, rendered by
`main.py` (pure Python standard library, no network, no fonts, no assets).

The gadget: an electric kettle that boils ice. It stands on a clean studio
backdrop, lit like a real product shot, and pours a stream of ice cubes from
its spout into a mug — the one accessory. The absurd job reads from the
picture alone: a kettle, doing the exact opposite of its job, presented as
though someone manufactured it and photographed it for a catalogue.

Run it:

```
python3 main.py            # writes /output/entry.png (or ./entry.png)
```

Output is a whole PNG, 1024×1024, under 1 MiB.
